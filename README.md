
# Ubuntu Python Desk

A starter desktop application built with Python and Tkinter.

## Run locally

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -e .
    ubuntu-python-desk

## Test

    python -m pip install pytest
    python -m pytest

## Packaging

The Snap packaging configuration is in `snap/snapcraft.yaml`.
